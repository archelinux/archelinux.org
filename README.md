# archelinux.org

Static website for the archelinux distribution. Open index.html locally or serve this directory with any static web server. GitHub Pages can serve the root of main. CNAME declares the intended custom domain, archelinux.org. Domain ownership, DNS and hosting are configured separately.

Layout inspired by [archlinux.org](https://archlinux.org/). Symbol and screenshots from [archelinux](https://github.com/archelinux/archelinux). The desktop features the [Twin Blades wallpaper](https://github.com/dharmx/walls/blob/e8d8a42e4fbecb2cf9619995edbc7ce19610bbd8/anime/aeb9uhrbr41a1.webp).
