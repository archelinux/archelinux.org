archelinux 2026.11.23

New installations enable the signed archelinux stable channel during setup. After your first login, run sudo pacman -Syu to upgrade Arch and archelinux packages together. If the channel was unreachable during installation, run sudo arche-enable-rolling once connectivity is available, then run the full upgrade.

Already running archelinux? Keep your installation. If you installed from the original 2.0.0 ISO and still use the bundled repository, follow the one-time channel setup.

Verify the ISO

Download the ISO, checksum, both detached signatures and release public key into one directory. Compare the key's fingerprint with your trusted copy of the archelinux release fingerprint, E446 C26A 0B7B A1A6 6A3D CC9F 7EC5 6400 3573 C80B.

iso=archelinux-2026.11.23-x86_64.iso
gpg --show-keys --fingerprint archelinux-release-public.asc
gpg --import archelinux-release-public.asc
gpg --verify "$iso.sha256.sig" "$iso.sha256" &&
  sha256sum -c "$iso.sha256" &&
  gpg --verify "$iso.sig" "$iso"

After verification, write the image to USB. The installation guide covers disk selection, encryption and the SwayFX workspace.

This image passed a guided UEFI installation to a fresh XFS disk. The installer verified and activated the public rolling channel, and the installed system booted into SwayFX. Build and boot test
