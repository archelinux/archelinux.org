archelinux 2026.11.23 (LTS installer, revision 2)

This 1,008 MiB installer boots Linux LTS and includes Wi-Fi firmware. Connect to the internet and select the tools you want. Before modifying the target disk, the installer verifies the signed archelinux channel. It downloads your selected desktop and tools from stable and Arch mirrors. A default installation includes Zen and LTS.

This is the second rolling snapshot dated November 23. It is 236 MiB smaller than the earlier rolling image. Existing installations can continue with sudo pacman -Syu. Rolling updates

Verify before writing to USB

Save this release’s ISO, checksum, both signatures and public key together in a new directory. Several snapshots share the date in the filename. Compare the public key’s fingerprint with your trusted copy of E446 C26A 0B7B A1A6 6A3D CC9F 7EC5 6400 3573 C80B.

iso=archelinux-2026.11.23-x86_64.iso
gpg --show-keys --fingerprint archelinux-release-public.asc
gpg --import archelinux-release-public.asc
gpg --verify "$iso.sha256.sig" "$iso.sha256" &&
  sha256sum -c "$iso.sha256" &&
  gpg --verify "$iso.sig" "$iso"

A fresh VM booted the LTS USB, installed the selected SwayFX workspace, and booted from the installed disk. The test checked the stable repository and both installed kernels. Installation guide · Build and VM results
