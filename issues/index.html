Report an issue

Check existing distro reports before opening a new one.

  • Hardware compatibility report for a physical device you tested.
  • Distro bug report for a repeatable problem with installation, packages, or the desktop.
  • Website issue for an incorrect guide, broken link, or display problem.

Include the steps and relevant error text. Review logs for private details before posting. For setup questions, visit the community forum.
