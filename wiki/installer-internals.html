Guided installer internals

The live console starts a downstream adaptation of Arch's archinstall 4.5 source. During the build, scripts/prepare-installer.sh copies the official Python runtime and translations into the ISO and applies the patch in installer/. Upstream handles partitioning, encryption, bootloader setup and credentials. The Arche menu adds software choices, which are included in the saved configuration and final review. Guided layouts use XFS, including when encrypted. New accounts use the packaged arche-zsh environment. Its pinned Oh My Zsh sources and license are packaged locally, and updates go through pacman. The ISO carries the Arche repository and obtains selected Arch packages over the network.

The guided path installs arche-workspace-defaults for user configuration and arche-maintenance for package recovery. Neither requires a desktop or pins a kernel. The complete compatibility packages remain available. Selecting local inference also installs the optional service definitions. Selecting NVIDIA DKMS installs headers for the selected kernels.

The fixed XFS layout, mount tuning and unattended QEMU path described below refer to the earlier installer. Its explicit --unattended interface remains available to existing callers.
