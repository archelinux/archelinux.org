Security reports and advisories

For a suspected vulnerability in the installer, signed package channel or distro configuration, send a private report to archelinux. For the standalone Waybar tools or cached rollback utility, send a private report to the tool maintainers. Include the affected version, impact and relevant configuration. Remove credentials and private logs before submitting.

Read published archelinux advisories and standalone tool advisories. Packages installed from Arch’s official repositories are tracked by the Arch Linux security tracker.

For a mirror or signature failure, check the clock and the mirror information. Keep signature verification enabled. For ordinary support, use the community forum.
