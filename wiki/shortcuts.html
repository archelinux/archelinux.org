Keyboard shortcuts

The shipped Sway configuration uses Alt for its window shortcuts. Super is the Windows or Command key. Older personal configs may use a different modifier. Return means Enter.

Action Shortcut
Open Foot Alt+Return
Open Fuzzel Alt+D
Focus a tile Alt+H/J/K/L
Move a tile Alt+Shift+H/J/K/L
Switch workspace Alt+1–9
Move a window to a workspace Alt+Shift+1–9
Close the focused window Alt+Shift+Q
Enter resize mode Alt+R, then H/J/K/L. Return or Escape exits.
Reload Sway configuration Alt+Shift+C
Lock the screen Alt+Escape
Cycle configured keyboard layouts Super+Space
Switch to text console TTY2 Ctrl+Alt+F2
Return to the running desktop from TTY2 Alt+F1

For terminal panes, follow the first session walk-through. To add or change bindings, see Configuration files.
