## Download and reconstruct

Download both ISO parts, the ISO signature, SHA256SUMS and its signature, and archelinux-release.asc. GitHub limits individual release assets to under 2 GiB.

    cat archelinux-2026.11.10-x86_64.iso.part01 archelinux-2026.11.10-x86_64.iso.part02 > archelinux-2026.11.10-x86_64.iso
    gpg --import archelinux-release.asc
    gpg --fingerprint E446C26A0B7BA1A66A3DCC9F7EC564003573C80B
    gpg --verify SHA256SUMS.sig SHA256SUMS
    gpg --verify archelinux-2026.11.10-x86_64.iso.sig archelinux-2026.11.10-x86_64.iso
    sha256sum archelinux-2026.11.10-x86_64.iso

Write the reconstructed ISO to installation media; the individual parts are not bootable images.

## Signed pacman repository

After verifying the public key and importing it into pacman's keyring, configure:

    [arche]
    SigLevel = Required DatabaseOptional
    Server = https://github.com/archelinux/archelinux/releases/download/v2.0.0-rc1

Before enabling the repository, verify the fingerprint above, then establish pacman trust explicitly:

    sudo pacman-key --add archelinux-release.asc
    sudo pacman-key --lsign-key E446C26A0B7BA1A66A3DCC9F7EC564003573C80B

Packages and repository databases are signed. The ISO's bundled staging repository retains its scoped local-build trust setting. The published repository above requires signed packages.
