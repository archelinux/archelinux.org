We are thrilled to announce the inaugural public release of Arche Linux, v2025.07.26 "Genesis"! This release marks the first stable milestone in our journey to provide a minimal, security-focused, and streamlined Arch Linux experience.

Arche Linux is for users who love the power and flexibility of Arch but want a hardened, bloat-free foundation without the manual setup overhead, mostly fast to code and develop. Our interactive installer gets you from a bootable USB to a secure, running system quickly and efficiently.

## Key Features
### Security First
Ships with the linux-hardened kernel by default, including security-enhancing patches and a more aggressive security configuration to protect your system from the start.

### Pure Arch Base
Enjoy the full power of a minimal Arch Linux system. We provide a solid foundation, leaving you in complete control of what software you install. No bloat, no pre-installed opinions—just a clean slate.

### Built-in Integrity Verification
Security starts with a trusted source. The arche-install script includes an integrated GPG and SHA256 check to ensure your ISO is authentic and has not been tampered with before you begin the installation.

## Getting Started
### Download the Assets:
Grab the ISO, checksum, and signature files from the "Assets" section below.

### Verify the ISO (Recommended):
Before installing, use the signature to verify the checksum file, then use the checksum file to verify the ISO.
Alternatively, you can use the verification tool built into the installer itself.

### Create a Bootable USB and Install:
Use your favorite tool (`dd`, Ventoy, etc.) to write the ISO to a USB drive and boot from it. The `arche-install` script will be available to run from the command line.
