# Security reports and advisories

For a suspected vulnerability in the installer, signed package channel or distro configuration, [send a private report to archelinux](https://github.com/archelinux/archelinux/security/advisories/new). For the standalone Waybar tools or cached rollback utility, [send a private report to the tool maintainers](https://github.com/archelinux/arch-tools/security/advisories/new). Include the affected version, impact and relevant configuration. Remove credentials and private logs before submitting.

Read [published archelinux advisories](https://github.com/archelinux/archelinux/security/advisories) and [standalone tool advisories](https://github.com/archelinux/arch-tools/security/advisories). Packages installed from Arch’s official repositories are tracked by the [Arch Linux security tracker](https://security.archlinux.org/).

For a mirror or signature failure, check the clock and the [mirror information](mirrors.html). Keep signature verification enabled. For ordinary support, use the [community forum](../community/index.html).
